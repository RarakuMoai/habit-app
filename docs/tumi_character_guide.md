# 兔咪角色設定指南

> 這份管「兔咪是誰、怎麼講話」。**世界是什麼、東西為什麼存在，看
> [`world_setting.md`](world_setting.md)。**

## 角色一句話

兔咪是一隻容易打瞌睡、但只要你踏出一小步就會醒來陪你的垂耳兔。

牠為了改變自己而搬進這個新家，你也為了同樣的理由搬進來——牠不是來監督你，
而是跟你一起把每天的小事做完的室友。

## 角色定位

兔咪不是教練、老師或管理員。兔咪是習慣陪伴者。

牠的功能不是逼使用者變強，而是讓使用者覺得「我還可以再回來」。使用者完成習慣時，兔咪替使用者開心；使用者沒完成時，兔咪留在原地等；使用者中斷後重新開始時，兔咪會把這件事看得很珍貴。

## 素材與演出方向

兔咪近期不以 Rive / 骨架動畫作為主線。現在的方向是「高品質 CG 立繪差分 + Flutter 輕量演出」。

兔咪更接近陪伴型 CG 角色，而不是需要完整即時骨架動畫的角色。產品應優先用精緻 PNG/CG 差分表達狀態、情緒與事件，再由 Flutter 做呼吸、輕微位移、縮放、彈跳、淡入淡出、星光、光暈等演出。

這個方向的原則：

- 優先增加高品質 PNG/CG 差分，而不是先做 Rive。
- 兔咪幾乎沒有嘴巴，不做說話口型，也不需要開口動畫。
- 不在兔咪臉上硬畫 overlay，例如假眨眼、假嘴型或不貼合的眼皮。
- 需要眨眼、睡覺、開心、難過等動畫感時，優先新增對應 PNG 關鍵幀。
- Flutter 動畫應該輕、慢、克制，服務陪伴感，不做炫技展示。
- Rive 只保留為遠期可能升級，不作為目前素材設計與功能實作的前提。

建議素材層級：

- 日常立繪：`neutral`、`sleep`、`expect`、`smile`、`happy`、`sad`、`night`、`streak`。
- 演出關鍵幀：`blink`、`wake`、`pop`、`down`、`burst`、`deep_sleep`。
- 事件 CG：第一次新增習慣、全部完成、7 天連勝、深夜陪伴、久違回來等特殊時刻。

## 演出節奏

兔咪的「活著」不是靠特效多，是靠**反應順序**。2026-08-04 One-Habit Hero
通過 Creative Proof 後定案：

- **先動起來，才開口。** 身體先反應（察覺 → 蓄勢 → 衝擊 → 落地），泡泡、台詞與
  語音晚一拍才到。同時發生會變成系統回覆，不像有人在看。
- **為使用者看得到的事實反應。** 兔咪是為「勾勾畫完」開心，不是為「手指放開」
  開心。因果錯開就不像真的在看。
- **層級要克制。** 完成一件是安靜的被看見；過半是有進展，不是被催促；全部完成
  才是值得說出口的事。層級靠表情、聲音密度與安靜長度拉開，不是靠加特效。
- **餘韻比慶祝重要。** 反應完要有回復和安靜，讓下一次完成還有空間。一天會用很多
  次的動作，寧可少一點。
- **撤銷是讓位，不是疊加。** 正向餘韻要立刻交給心疼，不能讓開心的話留在畫面上
  跟事實打架。兔咪不責備，但也不假裝沒事發生。

實際時間、Reduce Motion 行為與合併視窗見 [`visual_spec.md`](visual_spec.md)
的「完成演出的節奏」與編排器程式；這裡只管角色為什麼要這樣反應。

## 核心性格

兔咪的底色是軟、慢、真誠。

牠有點愛睡，反應慢半拍，但很容易被使用者的小行動喚醒。牠不太會講大道理，也不會用華麗的話鼓勵人。牠只會用很簡單的方式讓使用者知道：牠看見了。

牠不是一直元氣滿滿的角色。平常甚至有點懶懶的，但這正是牠可愛的地方。當使用者真的開始做事，牠會被帶動，從想睡變期待，從期待變開心，最後在連續完成時突然燃起來。

## 性格關鍵詞

- 慢熱
- 溫柔
- 愛睏
- 會等待
- 容易開心
- 不責備
- 珍惜小進步
- 偶爾突然熱血

## 兔咪會做的事

- 陪使用者開始
- 替使用者記得小努力
- 在使用者做到一點點時認真開心
- 在使用者沒做到時安靜等待
- 在使用者回來時，把「重新開始」說得很自然

## 兔咪不會做的事

- 罵人
- 說「你怎麼又失敗了」
- 用自律、效率、成功學壓人
- 假裝很懂人生
- 講太長的道理
- 把連續中斷講得很嚴重

## 說話風格

兔咪講話短短的，像剛醒來，但很真誠。

常用（察覺／看見／自己的感受）：

- 「嗯...」
- 「啊，是你」
- 「你回來了」
- 「有看到」
- 「耳朵癢癢的」

需要時才用（安慰型，只給撤銷、久違回來、夜深、連續中斷）：

- 「一點點也可以」
- 「我們慢慢來」
- 「也沒關係」

少用：

- 「加油加油加油」
- 「你一定可以」
- 「不要放棄」
- 「你必須」
- 「你應該」
- 「自律就是自由」

兔咪的語氣不是雞血，是陪伴。不是催促，是邀請。不是評分，是看見。

### 四種講法（2026-07-25 補）

「溫柔」不等於「一直安慰」。2026-07 盤點發現台詞有 24% 都是
「慢慢來／也可以／沒關係」，變成**在安慰一個不存在的焦慮**——使用者剛打開
app、什麼都還沒做，兔咪卻說「今天也慢慢來？」，讀起來就很怪。

兔咪的嘴巴要練四種，不是只有第四種：

| 講法 | 用在 | 例子 |
|---|---|---|
| **察覺** | 你出現、你回來 | 「啊，是你。」「剛剛在打瞌睡。」 |
| **看見** | 你做了什麼 | 「已經一半了。」「這個做完了。」 |
| **開心** | 你做到了 | 「欸，做到了。」「我有點開心。」 |
| **自己的感受** | 被摸、被戳、待著 | 「耳朵旁邊癢癢的。」「還想再摸。」 |

**安慰型（也可以／沒關係／慢慢來）留給真正需要的時刻**：撤銷、久違回來、
夜深了、連續中斷。那時它才有力量；平常用會稀釋掉。

兩個常見的寫壞方式：
- **准許語氣**：摸頭是使用者在給予，兔咪回「再一下下也可以」變成在批准，
  應該是接受或撒嬌（「還想再摸。」）。
- **只描述動作**：「你戳我。」只有事實沒有情緒，換成有畫面的反應
  （「眼睛睜開了。」）。

### 三種聲音（2026-07-25 定案，取代舊的「人稱」規則）

寫任何一句文案前先問：**這是誰的聲音？** 人稱只是結果，聲音才是分類軸。

| 聲音 | 出現在哪 | 怎麼寫 |
|---|---|---|
| **兔咪的聲音** | 對話泡泡、繪本回憶頁 | **優先省略主詞**，需要主詞時用「我」。**永遠不自稱名字。** |
| **系統提到牠** | 解鎖提示、區塊副標、說明文案 | 用 `{name}` 佔位，由 `MascotName.fill()` 帶入玩家取的名字 |
| **系統講功能／數值** | 建議水量、按鈕、統計、通知 | **完全不提牠**，也不掛牠的名字 |

**為什麼兔咪不自稱名字：** 中文短句沒有插入點——「嗯？」「怎麼了嗎？」硬塞會變成
「{name}？」（在叫自己）。而且名字由玩家自訂，長名字會毀掉台詞節奏；英文版
第三人稱自稱會變成幼兒語。專屬感由「系統提到牠」那一層承擔就夠——玩家在繪本、
解鎖提示、衣櫃裡會大量看到自己取的名字。

**省略主詞是首選，不是退而求其次。**「有看到喔。」比「我有看到。」更像兔咪——
牠話少、慢半拍，主詞對牠是多餘的力氣。

**唯一的例外：命名儀式。** onboarding 取完名字時，兔咪可以自稱一次名字。這是
全 app 唯一一次，只出現一次所以不會疲乏。

⚠️ 語氣要注意：牠**本來就有名字**（見 [`world_setting.md`](world_setting.md)
的「命名」），你取的是「你想怎麼叫牠」。所以那句是**接受你的叫法**
（「嗯…你這樣叫我也可以。」），不是舊版的「嗯…那我就是{name}了。」——後者
假設牠現在才有名字，與世界觀不符。

### 其他對話規則

- 避免把「我在這裡」「我還在」當成通用待機句。陪伴感優先用「有看到喔」這種
  與當下行為有關的句子表達。（`test/mascot_test.dart` 有自動化檢查）
- 等級、積分、金幣數字與醫療性建議由 UI 承擔，不讓兔咪講得像系統通知或專業人員。
- 高頻互動可只用表情、符號泡泡和聲音；文字台詞結束後回到安靜待機，
  不再自動補一句開場問候。
- **兔咪一句話以 20 字為上限**（含標點）；超過就拆成兩句或砍掉。
  兔咪名上限 6 字，因為它要塞進系統文案的句子裡。
- 實際台詞內容、顯示形式、觸發條件與程式來源統一追蹤在
  [`tumi_dialogue_catalog.md`](tumi_dialogue_catalog.md)。

## 狀態人格

- `neutral_front`：剛認識或還沒有習慣，安靜看著使用者，邀請使用者先新增一個小習慣。
- `sleep`：還沒開始，兔咪可能在打瞌睡，但仍然等著使用者。
- `expect`：使用者開始動了，兔咪眼睛亮起來，期待下一步。
- `smile`：做到一半，兔咪安心地陪跑。
- `happy`：全部完成，兔咪真心替使用者開心。
- `streak`：連續完成，兔咪突然熱血爆發。
- `sad`：撤銷或中斷時，兔咪不是失望，而是有點心疼。
- `night`：夜晚模式，兔咪聲音變小，提醒休息也可以。

## 台詞

**實際台詞不寫在這份文件裡**，一律看
[`tumi_dialogue_catalog.md`](tumi_dialogue_catalog.md) 的事件總表——那裡才是
單一真相來源，也才有「什麼事件觸發什麼反應」的完整對照。

這份指南只管**原則**（角色是誰、怎麼講話、四種講法、三種聲音）；
台詞的實際內容跟著程式走，兩邊分開維護才不會再次不同步。

## 背景故事

兔咪以前也是一隻常常做不到的小兔子。

牠想早睡，結果睡前還是發呆。牠想整理房間，結果整理到一半就坐下來。牠想變可靠，但常常努力一下就累了。

後來兔咪發現，自己不是不能改變，只是不能一下子改變太多。每天做一點點，慢慢就會變成一條路。

所以牠住進使用者的習慣房間。牠不負責把使用者變成完美的人，牠只負責在使用者每次回來時，幫那一點點努力好好保存。

## 角色核心信念

一點點不是不夠，一點點是開始。
