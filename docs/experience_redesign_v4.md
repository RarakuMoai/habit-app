# V4：前導站位與收合功能修正

2026-09-11，延續 `codex/experience-redesign`。使用者回報的是實際構圖與主要功能缺席，上一輪 analyze／測試通過不能作為視覺驗收。

## 根因與修正

- **前導取名站位**：舊版房間以全寬 `BoxFit.cover/topCenter` 鋪圖，兔咪卻在另一個縮小、有 padding 的功能場景內底部對齊，腳底與地毯沒有共同座標。改為在核准 1122×1402 原圖的地毯內部定義落點，房間取景與 252×252 角色舞台共同換算，保留原立繪、陰影、呼吸與換裝。矮視窗按實際可用高限制舞台，命名鍵盤開啟時仍讓位給輸入。
- **喝水**：舊版摘要大框、提示膠囊與紀錄堆疊爭用收合高度；達標時還把瓶身換成勾章。改為瓶身與數據同列，取消外層大框／重複進度線；一般收合瓶身最高184pt、展開264pt，達標仍保留瓶身。加水／減水／自訂同高52pt；目標與紀錄直接可用，最矮面板改為數據旁44pt圖示。保留公英制、資料寫入與達標邏輯。
- **四種計時**：舊 frame 要高度至少276pt、寬度至少380pt才建立面盤，402×874的正式收合框只有約248.4pt，直接落入純文字摘要。新版收合均建立面盤，以左側面盤／右側主要操作排列，快捷在下。402面盤約128pt、430約156pt；極矮視窗保留104pt面盤與主要操作，次要內容可捲動。超慢跑開始與BPM共框；390也依實際148pt控制列＋60pt快選＋間距分配，四種模式底部保留16pt。
- **開發者測試**：移除另開回憶頁與四個特殊事件的直接預覽，全部回憶統一在衣櫃閱讀。保留暫時全開開關與前導命名草稿預覽，資料統計／觸發／解鎖工具改為預設折疊。預覽仍不寫相處、正式解鎖、已讀或選項。
- **版本辨識**：「小習慣，慢慢長大」是已停用的V2歡迎頁，只在歷史比較出現。最新比較頁把歷史連結獨立收起，現行六幕前導不混排舊畫面。

本輪沿用既有完整房間美術；問題來自座標與版面分配，不需要為這些問題重繪兔咪或新增CG。
