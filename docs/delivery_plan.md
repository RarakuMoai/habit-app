# 推進與驗收計畫

本分支只承接 2026-09-12「封面 → 開始／繼續 → 初見／房間」隔離互動樣品。上次完整產品與架構提案保留為參考；未核准項目不在本輪展開。

| 階段 | 本輪狀態／下一個判斷 |
|---|---|
| 體驗樣品 | debug 專用 target、記憶體狀態、模擬帳號、既有 tokens／原圖／音訊服務；852 測試通過、雙尺寸 44 張截圖與三段影片；詳見 [交付紀錄](entry_cover_preview.md) |
| 視覺驗收 | 待確認核准封面；以本輪原生截圖／錄影判斷留白、三種開始方式、按壓、短初見與房間銜接 |
| 整合 | 本輪不接 production routes、OAuth、真實儲存／備份，不重構六分頁 |
| 測試版 | 目前只在 Mac 專用 iOS 模擬器；Mac 鎖定使原生背景切換未驗證，未安裝實體 iPhone／iPad |
| 正式發布 | 本輪未授權，不合併 main、不部署 |

先完成這段樣品並停在範圍內。最重要的下一步是使用者判斷封面素材與整段操作節奏，通過後才能另外決定正式接入範圍。

本輪為既有 Flutter／圖片資產的 UI 樣品，Mac 足以完成建置與模擬器檢查，未執行需要另一台 PC 的生成或算力工作；不據此推論後續素材製作的工具或算力限制。
