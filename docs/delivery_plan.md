# 工作推進、裝置分工與驗收

更新：2026-09-09。依使用者要求維護全局與下一步，涵蓋體驗、工程、測試版與正式上架。
本頁是可調整的推進建議；已授權的工作持續執行，尚未定案的產品範圍不自行擴張。
發布授權仍依 [AGENTS.md](../AGENTS.md)，公開上架檢查以 [prelaunch_audit.md](prelaunch_audit.md) 為單一來源。

## 回覆與協作方式

每輪開發完成後，依工作量簡短交代：

1. **本輪結果**：完成什麼、在哪個環境驗證、還有什麼限制；區分美術樣品、正式整合、模擬器與實機。
2. **全局位置**：本輪解決哪個主要問題，還有什麼會阻礙下一階段；不只追蹤當前一個小元件。
3. **下一步**：推薦優先一件、必要時最多三件，說明目的及與後續工作關係；有順序，不只羅列可能性。
4. **請使用者驗證**：給可開啟的圖片／影片或已可操作版本、明確操作和觀察點；已知缺陷先標明，避免重複排查。

問使用者時優先問會改變方向的少數問題，例如動作性格、節奏與介面理解程度。
程式檢查、素材完整性、模擬器與可自動化驗證由 AI 處理，不把整套 QA 丟給使用者。
有使用者回饋就更新結果與下一步；沒有回覆只代表尚未驗收，不自動記成通過。
等待美術／實機回饋期間，可繼續已授權且不依賴答案的檢查、工具準備與文件整理。
此要求是每輪工作的習慣，不代表已建立定時提醒或背景自動執行排程。

## 可用設備與任務分工

以下硬體依使用者提供記錄，不推測未提供的規格。

| 設備 | 已知資訊 | 分工原則 |
| --- | --- | --- |
| 目前 Mac | 使用者稱為 Mac NEO；本任務工作區在此 | Flutter 開發、Xcode／iOS 模擬器、介面檢查與整合；可在此完成的輕量素材處理直接做 |
| 另一台 PC | GPU：4070S；系統記憶體：32 GB；CPU：i7-12700KF | GPU 模型推論、動畫生成、渲染或大型批次處理的候選執行設備；具體任務先確認工具相容性與實測需求 |
| 使用者主要實機 | iPhone 14 Pro Max；iOS 與 App 版本依當次回報記錄 | 使用者通常直接用實機，以此作為手感、音訊、效能與外觀的最終驗收；AI 先做程式／素材自檢與模擬器補充檢查，不要求使用者改用模擬器，亦不安裝或啟動實體 iPhone／iPad |

32 GB 是使用者提供的系統記憶體，不能當作 GPU VRAM。第一次需要 PC 執行 GPU 任務時，
再確認實際顯示記憶體、作業系統、驅動、可用儲存空間與操作／連線方式；現在不為了記錄設備先要求安裝整套環境。
知道 PC 存在不等於已連線，也不代表任何模型必定能載入；不先承諾速度或品質。

遇到 Mac 瓶頸時：

1. 先確認是算力／記憶體、平台支援、素材缺件還是演算法／美術問題。換 GPU 不會自動修復不合理的手勢或遮擋。
2. 若是可轉移的運算工作，選一個代表性小樣，準備 PC 任務包：輸入副本、環境檢查、依賴與版本、執行指令、預期產物與驗證方式。
3. 確認可用操作方式後在 PC 執行或由使用者執行任務包，回傳結果、耗時與必要紀錄；不要求使用者自行研究整條管線。
4. 將可用產物帶回 Mac，驗證原圖身份、透明邊緣、尺寸、接縫與 Flutter 實際顯示。保留來源與可重現步驟。

## 全局現況與建議順序

已有正式首頁室友對話 v1；搬家前導仍為提案。使用者認為分層動作樣品不自然，於 2026-09-08
決定停止該實驗，維持現有兔咪圖片與原本姿勢淡入淡出，優先加強按鈕、空白處回饋和轉場。
完整造型套仍未實作，但不再是目前 UI 改善或測試版的前置條件。資料來源見 [roadmap.md](roadmap.md)
與[室友互動紀錄](tumi_roommate_interaction_proposal.md)。
這是當前順序建議，不是有固定日期的發布承諾。

本輪新增睡衣選款與製作可行性驗證；試作素材仍在本機，未通過正式素材檢查，不隨文件提交。
目前三款正面圖已供選擇、褲型依使用者回饋改為輕盈版；尚未選定款式或完成整套。
2026-09-09 使用者要求先試整套無服裝底圖下半部修正，再決定造型製作。13 張候選已在 `design_trials/tumi_core_lower_v1/` 本機產出；複驗後已整套退修，不隨文件提交、不替換正式資產。網頁原始輸出有透明 alpha，但有邊緣雜色與上半身漂移，因此只將下腹局部對齊合回原圖；13 張候選為 1024×1024，上半身、修改區外及原 alpha 逐像素保持不變。此版主要減弱陰影/皺摺，並未更改透明外輪廓，但目前品質不足以請本人核可。

後續原尺寸逐張複驗已將 v1 整套退修：smile/眨眼有噪點，night/sad/wake 等有水平接痕；固定遮罩、硬透明度門檻及垂直位移無法保證曲面一致。不得以保護區像素不變宣告美術通過。已建立本機逐張左右/疊圖/差異檢視與退修紀錄（`design_trials/tumi_core_lower_v1/audit/`），v2 已重新驗證局部編輯方法。核可後才替換底圖，再以睡衣與難姿勢驗證造型一致性；不得把底圖通過當作服裝必然穩定。其間仍可推進已授權的 UI 改善。

v2 的 13 張下腹局部候選已完成，全部待本人美術核可，正式素材未替換。重新生成的 13 張原始 PNG 均已透過瀏覽器公開素材匯出能力保存，見 [保存驗證紀錄](browser_image_download.md)；原生儲存視窗的操作異常仍未定位根因。因生成圖的修改區外仍有毛色／線條變化，只取下腹小範圍，以平滑遮罩合回原圖副本。本版淡化深摺線與陰影，沒有更改體型或透明外輪廓。

2026-09-09 檢查：13 張候選均為可解碼的 1024×1024 RGBA，alpha、頭手腳及局部修改區外逐像素不變，13 張正式原圖雜湊也未變。已逐張查看原尺寸下腹的淺／深底比對，未見 v1 的水平接痕與碎點；正面／眨眼做過靜態成對檢查，尚未整合至 App，不能當作實際轉換驗收。本機交付為 `design_trials/tumi_core_lower_v2/review/index.html` 與可獨立解壓檢視的 `tumi-lower-v2-review.zip`，逐張檢查記錄在 `review/metrics.json`。未核可試作不隨文件提交。下一步請本人確認下腹是否仍有裝重物感、腿根是否自然、兔咪原本感覺是否保留；核可後才替換並驗證淡入淡出，再進行睡衣。

| 階段 | 下一步與目的 | 進入下一階段的條件 |
| --- | --- | --- |
| 1. 介面觸控與轉場 | 先處理室友選項按壓，再做房間空白處的安靜點擊回饋，最後整理進出對話與頁面轉場；每次只驗證一個視覺問題 | 回饋看得懂、節奏舒服，不干擾原有按鈕／捲動／手勢；降低動態正確 |
| 2. 一段完整陪伴體驗 | 以現有兔咪圖片配合 MI、意思字幕、選項、主選單隱藏／恢復與返回操作，完整調整對話節奏；再處理首次相遇／搬家前導 | 從進入、回應到返回功能頁可完整走通，降低動態與中斷恢復正確；使用者能理解室友關係與如何開始習慣 |
| 3. 工程與核心流程收斂 | 檢查互動狀態、素材／音訊歸屬、儲存與主要流程；依實際耦合、重複與測試缺口做必要重構 | 沒有已知阻斷或資料損失問題，相關回歸檢查通過；重構依實際問題判斷，模型作者不是依據 |
| 4. 本人內部實機測試 | 提供可驗證版本與短步驟，測實際音訊、觸控、背景／恢復、換日、尺寸與耗電；幀率依 [frame_rate_strategy.md](frame_rate_strategy.md) | 機型、版本、操作與結果有記錄；已知問題分級，重要問題修復後複驗 |
| 5. 封閉測試版 | 與使用者確認首版範圍、測試者及回饋方式；準備分發、問題回報與版本追蹤。採用何種平台分發時再查當時官方要求 | 測試者能完成核心流程，主要問題收斂，有清楚的已知限制與候選版本 |
| 6. 正式上架與後續 | 依上架清單準備公開版本、商店素材與必要說明；使用者確認後才執行發布。上架後先處理崩潰、資料與阻斷問題，再依實際回饋排下一版 | 公開版檢查與使用者確認完成；發布、後續監測或排程需各自具備可用工具與授權 |

不要求一口氣完成全部動作、造型或新功能才測試。先取得可完整體驗的小範圍版本，讓真實回饋提早影響方向。

## 現在最需要的使用者回饋

以 **iPhone 14 Pro Max** 為主要實機；本輪四項操作與回報格式集中在 [實機回饋清單](iphone_feedback_checklist.md)。

- **先看選項按壓回饋**：在首頁聊天模式中按住選項、移開取消、放開選取；確認回饋是否清楚而不誇張，選項是否仍容易點到。先由 AI 提供模擬器結果，再請本人確認觸控手感。
- **再看正式首頁互動**：在包含對話 v1 的版本中，點聊天圖示、選一個回覆、返回功能頁；確認選項是否直覺、主選單消失／恢復是否自然、字幕與 MI 是否舒服。若本人版本尚未包含此功能，先準備對應版本與步驟，不要求驗證未安裝內容。
- **稍後才做效能定案**：互動特效與正式場景整合後，再由使用者做實機 profile／release 的幀率、音訊與耗電比較。現在的 GIF／debug 模擬器結果不當作上市效能結論。

當前驗收狀態：分層動作樣品已被使用者否決，停止精修及新增驗收要求；室友選項按壓回饋已完成首輪實作、模擬器版面檢查與自動測試，本人手感尚待驗證。下一個實作優先項目為房間空白處回饋。檢查環境與結果見 [互動工作紀錄](tumi_roommate_interaction_proposal.md#介面回饋第一輪2026-09-08)。
