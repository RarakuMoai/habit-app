# 網頁圖片保存與驗證

2026-09-09：適用於使用者已指定由 ChatGPT 網頁製作的兔咪圖片。
這份文件記錄本專案已實測的操作路徑，不保證所有網站或分頁都提供相同能力。

## 優先保存方式

1. 在瀏覽器確認生成已結束，開啟要保存的圖片。需要視覺判斷或操作結果不符時立即截圖。
2. 使用瀏覽器工具公開的 `pageAssets` 能力；先讀該能力文件，再以 `list()` 取得當前頁面素材。
3. 將可見目標圖片的 DOM `src` 與素材清單的 URL 精確匹配，避免拿到上傳原圖、縮圖或網站圖示。
4. 對匹配的單一 asset 呼叫 `bundle()`。不要自行用網路請求或未公開的瀏覽器介面下載。
5. 將工具回傳的本機檔案複製到本次試作 `raw/`，保留生成原始尺寸、格式與 alpha。
6. 確認檔案可完整解碼，記錄格式、尺寸、alpha、檔案大小、SHA-256 與生成來源。另製比對副本；保存成功不代表美術通過。

素材清單可能為空，或缺少目前圖片。此時不能猜 asset ID；先確認圖片已載入、目標是否正確，
必要時改用網站的正常下載介面。

## 原生儲存視窗

- 「儲存」視窗通常是在詢問位置及檔名，不能直接判斷為下載失敗或權限不足。
- 分開辨識「前往資料夾」與「儲存」兩個面板；選定位置後還要完成儲存。
- 操作沒有預期效果時，先取截圖和最新介面狀態，確認焦點、選取位置與按鈕。重新讀取完整狀態可能重編元素 ID，不能沿用舊 ID。
- 文字定位與實際結果不一致時停止重複點擊，改用當前截圖定位或已支援的鍵盤操作；座標操作也可能受工具支援限制。
- 一次只啟動一個下載。視窗消失後查目標檔案，確認成功或取消再決定下一步；不要盲目重按下載而堆積多個視窗。
- 不因單一按鈕灰色就要求開完整存取權、安裝外掛或改安全設定。

- 原檔本機位置：`design_trials/tumi_core_lower_v2/raw/tumi_neutral_front.png`；仍為未核可樣品，不隨文件提交。

不能只依輸出順序命名。這次十張經原圖比對及視覺核對後保存；保存成功仍不等於美術核可。

不能宣稱原生視窗已修復。上述素材匯出路徑讓本次圖片保存可繼續，後續仍需逐檔驗證。
