# 兔咪主線、故事前導與房間活動方向

更新：2026-09-11。這份文件整理本輪使用者提供的故事與產品方向。
「使用者指定」是本輪敘事基礎；「建議」仍是提案。現行 App 尚未實作本文件的主線、前導與房間活動系統。
角色聲音與演出原則見[角色指南](tumi_character_guide.md)，工程與帳號計畫見[製作藍圖](companion_story_and_accounts_plan.md)。
知名作品參考、14段情節與結尾樣稿集中於[第一季故事大綱](tumi_story_outline_v1.md)；本文件維護已確認設定與產品規則。
最新範圍修正：主線以聊天、CG與回憶呈現，不因寵物或返校情節新增系統功能。下方前導／備份／房間等既有產品提案分開討論，不擴大成故事製作的前置工作。

## 方向判斷

這條路線可發展成「有失落背景的溫暖成長故事」。兔咪有自己的願望與阻礙，習慣功能、相處與回憶因而有共同主題。
成敗在於如何寫責任、自責與支持：寵物離世不能只被當作催促自律的教材，使用者也不能負責拯救兔咪。
首週先建立兔咪值得喜歡的個性與日常，之後逐步理解過去；重點段落需有後續影響，平日仍有輕鬆與幽默。

## 使用者指定的故事基礎

1. 兔咪內向、害羞，早期生活懶散，過一天算一天。曾在學校被欺負，之後更不願接觸他人。
2. 牠養過一隻深愛的寵物，也是最好的朋友。牠會餵食、陪玩與清潔，但常忘記，父母平常會補上照顧。
3. 一次父母出遠門，兔咪忘記餵養，造成寵物離世。這份失去成為牠想改變的契機。
4. 牠把照顧疏漏、自己的內向與其他不順都連成「我很差勁」，希望成為外向的人並改善生活習慣。
5. 善良的父母支持牠試著獨立，必要時仍可求助；安排新住處與室友，希望牠逐步接觸他人。
6. 使用者也是想改變、養成習慣的人；各自原因不同，不替使用者指定創傷、年齡、職業或家庭背景。
7. 使用者與兔咪以室友／同伴相處，但不說死是長住還是偶爾來。兔咪確實住在這個家。
8. 三個月內逐漸從陌生、害羞走到熟悉、互相信任，一起經歷困難與開心的事。
9. 兔咪慢慢學會整理、與不熟悉的人說話、獨自採買，最後喜歡新家，也願意回去上學。使用者已確認結尾：牠接受自己的內向，仍能與人溝通；相處會累時可以休息，不必成為一直外向的人。
10. 本名是兔咪。初遇可自我介紹，使用者可以另取暱稱。過往隨對話與好感逐步揭露，主線可略過並收進衣櫃回憶，死亡過程不演出。前導改故事性，功能預設全開，關閉方式於後續教學提供。

兔咪採架空年齡，感受接近人類國中／高中階段，不在故事說死年級。
寵物採黃金鼠，暫名小麥，由作者命名、使用者讀稿後可改；作為聊天中回憶提起的朋友。依使用者修正，不細寫遠行天數、死因與照護流程，也不建立寵物系統。
父母暫以兩位家長存在，不延伸手足、姓名、職業等世界觀。

## 建議的敘事立場

### 兔咪起初相信什麼，故事最後讓牠學到什麼

| 層次 | 寫法 |
| --- | --- |
| 事故責任 | 保留照顧疏漏與不可挽回的失去，不用反轉成無關事故來抹掉原意。 |
| 兔咪的自責 | 「一定是因為我太差／太內向」是牠當時的想法，不能由旁白認證為真。 |
| 初期願望 | 保留牠想變外向的願望，讓使用者理解牠想重新接近他人。 |
| 成長的終點（使用者已確認） | 接受自己的內向；可以與人溝通，也會累、需要安靜。表達、拒絕、求助與可靠安排是具體成長，不必換成另一種性格才值得被喜歡。 |
| 使用者的角色 | 參與、傾聽、分享、一起試；可以幽默、安靜或稍後再聊，不用扮演專家或回答標準安慰話。 |

兔咪自己的習慣進展由故事與相處推進。使用者漏打卡、少喝水、數日沒開 App，都不能導致兔咪再失去誰、退學或受罰。
不把「照顧兔咪」做成需要每天餵養才能避免死亡的機制。歷史事件是既定過去，不是使用者可觸發的失敗結局。

### 家人支持與返校的敘事方向

- **父母的支持**：保留善良、願意幫忙，獨立生活是兔咪想嘗試的選擇。以幾次關心與實際協助呈現，不另寫事故調查或照護交接。
- **返校的條件（已確認）**：回原本學校，先交代欺負事件已受到處理，再寫兔咪願意踏出的一步。父母、校方等其他人物簡短帶過，主線仍集中兔咪與使用者；不要求牠討好欺負牠的人。

使用者已確認：過去透過對話與好感成長逐步透露，偶爾自然埋線索，不刻意懸疑化。
不演出死亡過程；可用兔咪哭泣等 CG、全頁圖片配旁白呈現失去。所有主線均能略過，之後從衣櫃回憶閱讀。
不能把沉重段落變成必答安慰題；具體台詞、圖片與揭露順序仍需審稿。

## 三個月主線草案

三個月是使用者指定的成長上限。下列 90 日用於分期估量；使用者已確認每日一次相處計進度，主動略過也算、重播不重複加分。好感顯示與缺席處理仍待定。
滿日數只代表關係階段與內容資格；收束需先處理必要前置（看完或主動略過），不能只因未讀而卡住主線。

具體章節改由[第一季大綱](tumi_story_outline_v1.md)單一維護：從初遇與採買，經過勉強模仿外向、逐步談過去與接受支持，到有準備地返校，最後以安靜相伴回收初遇。
大綱已列14段候選門檻、每段留下的日常變化、責任與自我接納的因果；章節及門檻仍為提案，不代表程式已有內容。

終點建議是「願意返校並完成第一步」，不壓縮成三個月保證完全克服所有困難。
返校不等於兔咪搬離 App；第 91 日仍在這個家生活，保留成熟關係、日常反應與節日擴充。
相處包含共同經歷困難，但不要求使用者披露自己被欺負或失去寵物的經驗，才能看懂或推進故事。

## 故事前導：先認識兔咪，再認識功能

使用者已指定採故事前導、可多張圖、功能預設全開。下面六段是可供製作的初稿，不是現行畫面。
建議先以現有場景檢驗台詞節奏，再製作 3–4 張有用途的關鍵圖；不要求每句一張圖。

| 段落 | 畫面／意思字幕樣稿 | 操作與用途 |
| --- | --- | --- |
| 到來 | 門口／房間的兔咪先察覺你，停一下：「你來了……」 | 繼續；保留直接開始的略過入口，不指定使用者有行李或搬入日期 |
| 自我介紹 | 「我叫兔咪。」／「你也可以幫我取個暱稱。」 | 保留兔咪或輸入暱稱，可稍後改；本名和暱稱不是兩隻角色 |
| 認識使用者 | 「那……怎麼叫你呢？」 | 使用者稱呼選填，可用中性稱呼先繼續 |
| 第一點坦白 | 「不太會和人說話。」／「不過，想試著改變看看。」 | 「我也有想改變的事」／「先慢慢認識就好」／「我其實也有點緊張」；回應不同，沒有好壞答案 |
| 輕鬆收尾 | 兔咪放鬆些：「剛剛想了很久的開場白……」／「好像只說出一半。」 | 可接幽默或安靜回應；用性格建立好感，不要求使用者先安慰創傷 |
| 進入日常 | 「以後，想說話可以來找我。」 | 進習慣主頁；可選加第一個習慣或先看看，不預先寫入假完成紀錄 |

前導先不講寵物死亡，也不塞水量、身高、體重、生日、孩子名單與六項開關。
首次使用功能時，才提供簡短教學與真正需要的設定。功能可關的教學由介面承擔，兔咪不用念設定說明。
故事可略過，必要設定可用預設完成；「稍後再聊」保留進度。暱稱和必要設定先可靠保存，最後才提交完成旗標。重看不重命名、重開功能或重加習慣。
已有使用者與雲端還原保留原暱稱、開關、相識日期與紀錄，新前導改成可選重看。

### 全功能開啟的語意

「全開」只代表首次新存檔可看見各功能入口，不等於使用者已設定所有功能：

- 習慣可空白；喝水開啟不自動新增喝水習慣；由首次使用決定是否加入。
- 體重頁可見，但不杜撰身高、體重、生日、性別或個人目標；資料不足的推算項目保持待設定。
- 家庭頁先呈現新增孩子的空白狀態，不自動造孩子、給積分或跳過家長管理設定。
- 計時器可有通用預設，使用者紀錄仍從實際操作產生。
- 新預設只作用於新存檔；不能更新 App 後把舊使用者關掉的頁面重新打開。

## 對話選項：讓不同個性都找得到位置

每個選項先定「這句話想表達什麼」：共鳴、實際建議、幽默、傾聽或界線。依情境取 2–4 個，不每次固定同一套餐。
使用者不必每次都善於鼓勵；可以說不知道、自己也會、先安靜或晚點再聊。
幽默取自情境與兔咪個性，不拿霸凌、寵物死亡或內向本身當笑點；使用者已指定不使用諧音與難以跨語言成立的文字技巧，寫法與審讀原則集中於[角色指南](tumi_character_guide.md)。

採買回來的日常示例（樣稿）：兔咪「結帳時，差點只會點頭。」

| 使用者選項 | 兔咪回應方向／樣稿 |
| --- | --- |
| 「我也會突然腦袋空白。」 | 共鳴：「原來……不只我會。」 |
| 「最後有順利買到嗎？」 | 關心結果：「有。」「走出店門才鬆一口氣。」 |
| 「下次先練一句？」 | 共同準備：「那……先借你當一下店員。」 |
| 「我今天想安靜待著。」 | 尊重界線：「好。先不練了。」 |

選項沒有「正確人格」。不把一次選擇永久標記為內向／外向／心理狀態；具體共同經驗才以穩定事件ID保存。
後續個人化回應只能引用確實選過／完成過的事；略過、退出與閱讀完成分開，不因重播重發獎或加好感。
需要新表情才提出對應差分，不為湊素材先寫大量特殊動作。

## 衣櫃回憶與略過規則

使用者指定衣櫃回憶可分「主線」「特殊事件」，已解鎖內容能點選重看；主線逐步透露背景。
建議保留首次相識、原有四則回憶等既存ID與日期，遷移分類而不刪收藏。

| 動作 | 主線／存檔結果 | 回憶呈現 |
| --- | --- | --- |
| 看完本段 | 前置已處理，保存實際選項與首次完成時間 | 解鎖，可重看；讀完標已讀 |
| 略過劇情 | 明確視為本段已處理，可接下一段；不替使用者選個性答案 | 解鎖並標未讀，稍後可完整重看 |
| 稍後再聊／系統返回 | 保存所在節點，仍待續讀；不等同略過 | 已有內容不丟失，維持未完成 |
| 重看 | 使用當時已選答案或不寫入狀態的閱讀分支 | 不加好感、不重發獎、不改首次日期 |

略過時，必要的故事事實可按預定主線往下延續；不讓後續兔咪說「你上次說過……」卻其實沒有選過。
重要選擇若影響主線，需有不代言使用者的中性後續；不能將隱藏預設答案寫成使用者選擇。
每日一次相處計進度已確認；建議將當日首次相處對話看完或主動略過記為一個相處日。
每日相處可使用既有日常台詞池，不要求每天都有未讀主線；當天即使沒有新故事，仍有能計進度的相處。
僅開提示、稍後再聊、普通摸頭與重播不另計；跨日完成按完成時的邏輯日判重。初遇也可作首日相處。
每天仍可再聊已解鎖內容，當日不重複加分；從衣櫃回憶回放才是永遠不加分的重播。
成熟程度由相處日數衍生，上限暫以90日表達三個月，無須準備90段從未讀過的主線。
揭露段落可採全頁 CG＋兔咪視角旁白，再回到對話；圖片與旁白可回看，無死亡過程演出。
不把所有未讀回憶依次自動彈出；衣櫃有未讀提示，由使用者選擇閱讀。

## 兔咪在房間生活：候選產品方案

使用者正在考慮「不每頁都在、可能在某個房間活動、最常習慣頁」。建議採一個位置狀態，固定有可到達的見面入口。
這是方向提案，尚未改動任何頁面的兔咪或排版。

1. **習慣主頁是常駐回家位置。** 最初版本沒有足夠專用姿勢的活動只用真實已有圖／台詞表現，不拿站姿宣稱已畫打掃。
2. **一次只在一個主要功能場景。** 房間、活動與劇情占用由同一狀態決定；切換分頁不重新抽位置，也不讓牠同時喝水與睡覺。
3. **始終有「找兔咪」入口。** 顯示牠目前在哪，點入可前往或進入可用的會面场景；不回到固定右上角的永久聊天鈕。真正有事件時仍在兔咪旁顯示短提示，點下才對話。
4. **關閉功能不關掉兔咪。** 所在房間被關閉時，改回習慣主頁；若未來也允許關習慣功能，保留其中的見面場景與入口，不把「關習慣追蹤」等同刪掉住處。
5. **主線沒有功能死路。** 主線可在主頁／獨立事件畫面重演所需環境，不要求啟用體重、建立孩子或完成特定水量。功能專屬支線可暫停提供，但不能擋住整體關係成熟。
6. **邀請與活動要穩定。** 對話中不因一般活動搬房間；背景暫停、回前景恢復。所在功能失效優先處理：先可靠保存節點，再回可用會面場景續讀，不計完成或相處進度。已排入但房間失效的邀請重新安置。
7. **外出不是失聯。** 超市／返校以可完成的事件演出與回來分享表現；不強迫等到真實放學才見得到兔咪。是否需要真實作息，放到日後另議。
8. **功能照常清楚可用。** 兔咪不在時不留下大塊空場景，收合功能保持完整；功能回饋由介面承擔，不從別房間突然彈出兔咪語音。

「只顯示一隻」適用主要生活場景；回憶封面、衣櫃預覽與歷史照片不算第二個同時活動的兔咪。
精確位置、活動頻率、找兔咪入口版位與關閉流程需原生樣品驗證，不先堆一整套房間模擬系統。

### 已核對的程式限制（尚未修改）

- 現在習慣與衣櫃固定存在，另外四項可關，可沿用習慣頁作保底。[分頁組裝](../lib/main.dart)
- 七處場景各自建立兔咪並訂閱全域人格，還沒有單一位置；全域互動可直接播 MI，藏圖不能防止無來源語音。[場景](../lib/widgets/mascot_scene.dart)、[人格與語音](../lib/utils/mascot.dart)
- 面板開合目前全 App 共用，shell 仍預留場景高度。新方案要一起調整角色、場景空間、開合與語音，不能只加透明度。[頁面容器](../lib/widgets/mascot_page_shell.dart)
- 喝水開啟會補每日習慣、刪掉喝水／體重習慣又會關工具頁。MainPage每次套用設定也執行reconcile，只改前導仍會補習慣或被保留習慣反開頁面。預設全開前先拆「頁面可見」與「加入每日習慣」，位置校正須涵蓋所有關閉入口。[喝水連動](../lib/utils/water_habit_link.dart)、[功能設定](../lib/pages/feature_settings_page.dart)
- 舊前導可保存已輸入但略過的有效欄位，且先寫完成旗標。故事前導須有獨立初始化／取消／重播流程；新預設不能先跑進還原存檔。[前導](../lib/pages/onboarding_page.dart)
- 主線不能沿用「已有完成的每日習慣才邀請」作唯一條件；空清單、只有每週習慣也應可相處。[現行邀請](../lib/utils/roommate_events.dart)
- 現行StoryStore會濾掉未知事件ID，並可能清理未讀後寫回。新格式須先保留未知事件原始紀錄等待更新，不替換成第一則故事、不標完成，再進行讀取。[回憶保存](../lib/utils/story_store.dart)
- 喝水有通用預設值，沒有生日就不走兒童分支；缺身體資料不能稱已完成個人化建議。家庭未設 PIN 也不是已受保護，須在首次設定說明。[喝水](../lib/pages/water_page.dart)、[家庭驗證](../lib/pages/family/family_auth.dart)

### 可驗證的失效情境

- 關閉兔咪所在的頁面、只留最少功能、從失效位置存檔重開，都可到達兔咪。
- 關閉家庭且沒有孩子、關閉喝水／體重，仍能取得主線與返校事件資格。
- 對話中切到設定關功能、切分頁、背景、跨日、重啟，無幽靈語音、重複角色、遺失節點或永久隱藏導覽。
- 功能頁收合、繁中／英文長文、大字級／小螢幕，主要按鈕不因拿掉場景而移出可用區。
- 缺新圖、舊內容版本、未知房間／事件 ID，使用已核准中性立繪與主頁作回退，保留存檔等待更新。
