# 兔咪好習慣 — 現況與產品決策

更新：2026-09-08。這份文件提供背景，不是待執行任務清單。
產品方向調整由使用者決定；實際功能、素材集合與數值以 repo 為準。

## 核心原則

- **習慣陪伴**：兔咪安靜陪使用者完成每天的小事，不責備、不監督、不評分。
- **無廣告**：保留安靜的陪伴體驗。
- 新功能要增加陪伴感與實際用途，避免帶來額外壓力或雜務。
- 重視程式品質與長期可維護性。

角色說話原則見 [`tumi_character_guide.md`](tumi_character_guide.md)；
技術護欄見 [`engineering_guardrails.md`](engineering_guardrails.md)；
既有樣式見 [`visual_spec.md`](visual_spec.md)。

## 現階段決策（可以重新討論）

- 目前以自用開發為主，暫不上架，沒有硬性上架時程；未來以台灣繁中優先。
- 核心習慣追蹤以免費且大方為方向；免費範圍與長期承諾，待變現方式確定後再決定。
  不把「永久免費」當作已對外承諾。
- 目前不做記帳；若使用者日後提出新需求，再按用途與陪伴定位評估。
- 底部分頁目前 6 個。新增分頁需有反覆使用的核心用途，既有頁面或彈窗可承載時
  優先使用它們；6 不是永久上限或必須湊滿的數量。
- 裝飾與金幣目前服務互動和陪伴，是否商品化留待變現規劃。
- 訂閱、買斷、造型上新與同步服務都未定案，不從舊文件推定開發優先順序。
  造型一致性是需要驗證的製作問題，其結果不能直接決定訂閱或買斷。

## 目前素材實作方式

- 兔咪採 CG／PNG 差分與 Flutter 輕量演出；核准底圖局部編輯，不重繪整張。
- 造型整套替換；正式造型要覆蓋 `assets/mascot/core/` 的完整 PNG 集合，
  包含啟用的眨眼差分。以 `MascotEmotion` 與造型資產測試為準，不另鎖固定張數。
- 四時段背景由同一核准底圖局部編輯，保持鏡頭、家具與兔咪站位一致。
- 製作工具依當次任務與可用技能選擇，不限定必須手動貼到 ChatGPT。
  不把既有訂閱額度或舊成本假設寫成永久零成本。
- 素材候選與 prompt 草案見 [`pending_assets.md`](pending_assets.md)，不代表排程。
