# 故事前導：從這次相遇開始

2026-09-11，`codex/experience-redesign`。本輪目標是讓使用者先認識兔咪與這個家，再開始使用功能。
使用者授權大改前導；這不是帳號註冊、備份或新CG的實作。

## 六幕初遇

1. 走進家裡：空房與短旁白，先留一點空間。
2. 初次招呼：兔咪有點緊張，介紹本名。
3. 新的生活：剛搬來，學著安排生活、主動與人說話。
4. 兔咪的暱稱：可以沿用本名，或留下自己的稱呼。
5. 使用者的稱呼：可以空著，不要求個人經歷與身體資料。
6. 一起開始：兔咪想分享日常，進入習慣首頁。

前導及其回憶共用 `lib/utils/onboarding_story.dart`。沿用核准的白天房間與兔咪立繪，
不修改全域時段或服裝。沒有逐字強制等待、每頁提示音或完成慶祝；使用者控制前進與返回。
第一次進首頁保留每日登入獎勵入帳，但不立刻接全螢幕報到。下次登入仍照原流程。
開場不提小麥與霸凌，也不提前替兔咪完成「接受內向」的結局。

## 稱呼、略過與回憶

- 兔咪暱稱沿用中6／英12的顯示寬度限制，使用者稱呼最多12字位。
- 空值不存為名字；預設兔咪名會隨介面語言切換。既有資料不由預覽覆寫。
- 右上可略過整段。看完與略過都完成 `story_01`，當天最多計一次相處；略過的回憶保留未讀。
- 衣櫃 → 回憶 → 主線 →「從這次相遇開始」可重看；稱呼只讀，看完只標記已讀。
- 設定 → 開發者測試 → 回憶 →「預覽故事前導」可重新試讀與輸入草稿；退出不改存檔、名稱、音量、相處進度或已讀。
- 既有使用者不被強制回到前導；尚未完成初遇的舊用戶仍可從首頁既有逐句對話入口遇見 `story_01`。

## 初始化與接續

`OnboardingSetup` 的寫入可重試，`onboardingDone` 在必要資料確認成功後才保存。
相處資料由既有的單一JSON原子提交；後續設定失敗時，重試不會重複增加相處日。
背景跨過換日線後，完成前導前先等待既有換日協調器完成，避免使用過期日期。

新存檔的喝水、計時、體重與家庭入口預設全開；習慣與衣櫃原本固定存在。
不產生預設習慣、假健康紀錄或小孩；既有false開關不被初始化覆寫。
`onboardingStoryVersion=1` 只讓新前導避開「開啟喝水就自動建立第一個習慣」的舊資料補齊。
手動功能開關與原本已存在的喝水習慣同步維持原行為。
設定的基本資料也允許不填使用者稱呼，後續可以直接補身高／體重。
