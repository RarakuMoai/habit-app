## 本輪範圍

- 底部以玻璃材質為主，未選中的圖示再淡一些。
- 收合面板盡量保留主要功能；體重等資訊量大的頁面仍可展開。
- 四種計時收合時，基本快捷操作不應被大面盤與說明擠到下方。
- 喝水收合仍要有水瓶，展開時水瓶更大。
- 習慣首頁要更明亮活潑；設定列的圖示與標題／說明整組對齊。

## 已實作的布局

### 玻璃導覽與配色

`NAV_GLASS` 預設改為 `true`，以 Flutter `BackdropFilter` 的18pt模糊、
由白色到暖白的半透明漸層及細亮邊呈現玻璃。選中項目有獨立亮面膠囊，
未選中 PNG 透明度由0.56降為0.42，文字保留可讀對比。高對比模式回到實底、
圖示全亮；降低動態省略圖示的透明度補間。這是 Flutter 玻璃材質，並非 Apple 原生 Liquid Glass。

首頁加號與進度使用杏桃／珊瑚色，完成圓圈改為清楚的綠色漸層、卡底改為淡薄荷，
取消原先綠色混暖棕造成的暗濁感。專注維持柔紫，節拍器改為暖琥珀。
實際 token 以 `app_style.dart` 為準。

### 四種計時收合

沿用 V2 實際 parent：`MainPage → SafeArea → MascotPageShell → 模式列 → TimerModeFrame`。
430×932、上59／下34pt安全區時，收合後真正的計時內容只有 **277.8pt**。
上一版先排176pt以上面盤、狀態說明，再排快捷列，是基本操作被擠出畫面的主因。

V3 先分配44pt狀態／設定列與快捷列的自然高度，再把剩餘空間交給面盤與操作區。
開始／暫停52pt、次要操作48pt。一般模式的面盤約160–172pt；最密的超慢跑包含48pt即時BPM列、4pt間隔、68pt五種運動列，
面盤依剩餘空間縮至約108pt，
整組主要功能仍能在收合範圍內操作。說明、重複進度與統計接在快捷列之後，可捲動閱讀。

| 模式 | 收合直接操作 |
| --- | --- |
| 專注 | 開始／暫停、重設、跳過、設定、四個方案；執行中原本鎖定的項目維持鎖定。 |
| 運動 | 開始／暫停、重設、跳過、設定、五種運動；超慢跑即時BPM加減也保留。 |
| 節拍器 | 開始／停止、速度加減、設定、TAP、拍號、細分。 |
| 遊戲 | 開始、玩家數、骰子、設定及三種玩法；棋鐘固定兩人的規則不變。 |

430pt中英文、1.3字級直接驗證每個快捷目標位於可見範圍並可點擊。
320×667與雙排導覽的計時內容只剩122.9pt，無法同時容納全部44pt以上的操作；
此情況先保留即時操作，快捷列緊接其後，可捲動或展開使用，不縮小整組觸控區。

### 水瓶與設定列

水瓶在收合／展開都保留，總量、目標、加水、復原與自訂入口仍可使用。
430pt收合水瓶高156pt，展開高216pt；極矮面板依實際高度縮至至少72pt。
沿用真實水位、完成狀態、加水回饋與降低動態，不用靜態插畫替代水量資訊。

設定入口改為自然高度的 Row，44pt圖示、整組標題／說明及箭頭垂直置中；
標題與說明共用左緣，長字可換行。測試使用正式 SettingsPage 的實際文字與捲動載入。
