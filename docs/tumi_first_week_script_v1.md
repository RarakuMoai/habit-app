# 兔咪初遇與前七次相處腳本 v1（幽默修訂）

更新：2026-09-11。原創可審讀稿，尚未接入 App 或生成圖片。對應[第一季大綱](tumi_story_outline_v1.md)的前導、第02／03段主線，以及穿插日常。

最新設定：黃金鼠暫名小麥；兔咪最後回原校，先交代欺負事件已受處理；敘事集中兔咪與使用者，其他人物簡短帶過。
小麥與校園往事留到後段自然提起。首週先讓使用者認識兔咪的慢半拍、坦白與願意聽人說話。
本輪依使用者要求排除諧音及語言雙關；日常不必每段逗笑，少量幽默候選仍待審讀，不能把本稿當成已驗證好笑。原則集中於[角色指南](tumi_character_guide.md)。

以下「第幾次」只方便審稿排序；沿用已確認每日一次相處與略過規則，不另定缺席或系統功能。台詞只表達故事，不指示功能開關、任務完成或新數值。
每處選項選一項，接對應回應後回到合流。未選答案不視為使用者說過；略過、稍後與回憶由原有產品規劃處理，不塞進兔咪的台詞。
分鏡是簡要演出意圖，先用現有核准場景與表情閱讀；不要求新道具常駐場景，也不代表原生畫面已完成。

## 第1次｜說出一半的開場白

**作用：**自我介紹與稱呼、說出想改變的願望，讓初遇自然放鬆。使用者來訪方式不說死。
**簡要分鏡：**房間裡的兔咪察覺你 → 猶豫地招呼 → 對話與稱呼 → 比剛才放鬆。預估1–2分鐘，依閱讀速度調整。

兔咪：「啊……你來了。」

兔咪：「我剛剛在練習打招呼。」

兔咪：「結果，只記得這一句。」

兔咪：「我叫兔咪。」

兔咪：「你也可以幫我取個暱稱。」

稱呼操作沿用前導規劃：可保留兔咪或取暱稱。保留時接「嗯，叫我兔咪就好。」；取名時接「嗯，這個稱呼也喜歡。」

兔咪：「那……怎麼叫你呢？」

使用者稱呼可選填；有填或稍後再說均可繼續，不替使用者編名字，也不要求說明自己的背景。

兔咪：「最近才住進來。」

兔咪：「還在學著自己安排生活。」

兔咪：「也想變得外向一點。」

兔咪：「這樣應該……比較好相處吧。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「我也有想改變的事。」 | 「原來，你也有。」「那……就慢慢認識吧。」 |
| 「先照你習慣的方式就好。」 | 「好。」「不過，我可能會停頓很久。」 |
| 「其實我現在也有點緊張。」 | 「啊，那我們一樣。」「剛才還以為只有我。」 |

合流：兔咪「準備了很久的開場白……」

兔咪：「好像只說出一半。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「另外一半，留著下次說。」 | 「好。」「希望下次還記得。」 |
| 「這樣就認識了呀。」 | 「嗯。好像真的認識了。」 |
| 「我先看看這裡。」 | 「好，你慢慢看。」 |

收尾轉入日常。先不講小麥、受欺負或事故；不要求約好每天見面，不以沉重告白留人。

## 第2次｜回話慢半拍

**作用：**讓兔咪說出相處時的小習慣，使用者可以有自己的聊天節奏。
**簡要分鏡：**看見你後停一下 → 忽然想起要說的事 → 選項後略微放鬆。約30–45秒。

兔咪：「有件事，想先跟你說。」

兔咪：「我回話，有時候會慢一點。」

兔咪：「不是故意不理你。」

兔咪：「有時候在想，要怎麼說清楚。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「我也常常想很久。」 | 「那剛剛……」「可能是兩邊都在想。」 |
| 「我倒是很容易一直講。」 | 「那我可以先聽。」「想到什麼，再慢慢接。」 |
| 「安靜待著也不錯。」 | 「嗯。」「好像不用急著把空白填滿。」 |

合流：兔咪「這件事也想了一會兒。」

兔咪：「現在總算講完了。」

## 第3次｜今天的小事

**作用：**兔咪主動關心你，也分享自己的日常。這段先作普通聊天，不承擔笑點。
**簡要分鏡：**自然招呼 → 依選項接話 → 留在放鬆的日常表情。約30–45秒。

兔咪：「今天過得怎麼樣？」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「今天還不錯。」 | 「那就好。」「聽你這樣說，滿開心的。」 |
| 「換你說一件今天的小事？」 | 「想起以前看過的一本書。」「明明知道結局，還想再看。」 |
| 「今天沒什麼想說的。」 | 「好。」「那就先待一會兒。」 |

各分支自然收尾，沒有主持人設定或預先宣布的笑話。

## 第4次｜還沒全部做好

**作用：**對應主線第02段。讓使用者看見兔咪愛拖延，也願意說出沒做完的部分。
**簡要分鏡：**想分享又有點不好意思 → 說出整理經過 → 選項後坦然些。約45–75秒；整理用轉述，不展示可操作的新物件。

兔咪：「整理桌子時，翻到一本漫畫。」

兔咪：「本來只想看一頁。」

兔咪：「桌子還沒整理完。」

兔咪：「漫畫倒是看完了。」

兔咪：「後來，還是收好了一小塊。」

兔咪：「本來想全部做好，再跟你說。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「我也很容易被別的東西吸引。」 | 「明明只想看一下。」「抬頭才想起原本要做什麼。」 |
| 「那一小塊整理完，感覺怎樣？」 | 「看著，還滿舒服的。」「想先讓它保持這樣。」 |
| 「下次先把漫畫收起來？」 | 「嗯，先不要翻開。」 |

合流：兔咪「剩下的，想分幾次做。」

兔咪：「我講了好多自己的事。」

兔咪：「你呢？有沒有想分享的？」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「今天有件事做得還不錯。」 | 「喔，替你開心一下。」「今天多了一件好事。」 |
| 「今天不太順，想休息一下。」 | 「嗯。」「那就先休息，改天再聊。」 |
| 「我比較想知道那本漫畫。」 | 「冒險故事。」「這次有把它放回書架了。」 |

## 第5次｜只是來看看你

**作用：**讓使用者能來聊天、說自己卡住，或單純探望；兔咪接得住各種相處方式。
**簡要分鏡：**兔咪望向你 → 短短邀請 → 分支各自收尾。約30–60秒。

兔咪：「今天，換我當聽的那個？」

兔咪：「沒有要問很正式的問題。」

兔咪：「有想到什麼，再說就好。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「有件事一直拖著，還沒做。」 | 「我也有。」「說出來，好像不用先裝沒事。」 |
| 「今天想聽點輕鬆的。」 | 「有次想看完最後一頁再睡。」「醒來，書還在同一頁。」 |
| 「其實只是來看看你。」 | 「喔……」「看到你，滿開心的。」 |

各分支到此收尾，不再把你沒分享的事追問出來。兔咪有自己的生活，也能單純因為見到你而放鬆。

## 第6次｜像棉被的雲

**作用：**保留一小段沒有問題要解決的安靜閒聊，不把比喻當成已成立的笑點。
**簡要分鏡：**想起一件小事 → 聽使用者的想像 → 收尾。約20–30秒；轉述不綁當下天氣，不需新雲景。

兔咪：「有次看到一朵雲。」

兔咪：「很厚，看起來像一大團棉被。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「感覺很舒服。」 | 「嗯，看了好一會兒。」 |
| 「我以前也看過像動物的雲。」 | 「原來你也會看。」「下次，我也找找看。」 |
| 「聽你說，我也有點想睡。」 | 「那就先休息一下。」 |

各分支到此結束，刪掉借棉被、耳朵躺平與重複說想睡的尾句。

## 第7次｜沒有問出口

**作用：**對應主線第03段。小小的不順可以坦白，使用者能共鳴、陪練或安靜聽。
**簡要分鏡：**想起採買時的事 → 坦白沒有問 → 選項後決定下次再試。約1分鐘；店員僅在轉述中帶過，不另立固定角色。

兔咪：「去買東西時，找了好幾圈。」

兔咪：「明明有店員經過。」

兔咪：「可是，話一直沒有說出口。」

兔咪：「本來想說，只是剛好沒貨。」

兔咪：「但其實……我沒有問。」

| 使用者選項 | 兔咪回應 |
| --- | --- |
| 「我也會先多繞幾圈。」 | 「每次都想，下一圈就問。」「結果先把走道記熟了。」 |
| 「先練一句『不好意思』看看？」 | 「好。那……」「不好意思。」「嗯，這句先記住。」 |
| 「你先說，我聽。」 | 「嗯。」「講出來，有點不好意思。」「但不用想別的理由了。」 |

合流：兔咪「下次，想再試試看。」

兔咪：「要是又卡住，再跟你說。」

本段完成一個關係變化：牠願意讓你知道沒做好的事。下一段採買成功由兔咪自己準備、再試一次後發生。
只有真的選過陪練，後續才可提起共同練習；其他選項與略過使用者皆有自然的主線後續。

## 這份稿先看什麼

1. 初遇的兔咪是否內向但有趣，沒有過多自我否定。
2. 第3、5、6次作輕鬆聊天；第4次漫畫與第7次繞走道先當少量幽默候選，判斷是否自然、有共鳴，沒感覺就改或刪。
3. 選項是否有你真的會說的話；指出不自然的句子即可，不必替每段重新寫一套答案。

後續依讀稿回饋直接改句子與節奏，再製作確認段落的原生互動樣品。小麥的名字可在牠正式進入回憶的腳本中一起審。
