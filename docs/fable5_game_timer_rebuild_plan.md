# FABLE5 任務書：重建計時頁遊戲計時器

## 任務背景

目前「計時 > 遊戲」舊版實作已經清空，只保留 clean-room placeholder 入口。

請不要把這次當成舊功能改版。這次目標是從 0 建立一個新的桌遊/下棋計時器。

## 重要限制

- 不要參考已刪除的舊遊戲計時器實作。
- 不要讀取或依賴 git history 裡的舊版 `game_clock`、`game_session`、`game_widgets`、`game_fullscreen_page`、`game_settings_sheet`。
- 不要沿用舊互動邏輯、舊資料結構、舊 prefs key、舊測試。
- 目前 `GameTimer` placeholder 只代表 App 導航入口，不代表設計方向。
- 美觀度是第一優先，功能完整度是第二優先。

## 產品定位

建立一個全新的「桌中央輪流計時器」。

主要使用場景：

- 手機或平板放在桌子中央。
- 2 到 6 人圍桌玩桌遊或下棋。
- 玩家需要很輕鬆地點一下手機，就能換到下一位。
- 適合拉密、桌遊輪流行動、二人棋類、多人聚會遊戲。

核心成功標準：

- 放在桌上遠看也清楚。
- 一眼知道目前輪到誰、剩幾秒、下一位是誰。
- 多人桌遊時，任何人從任意方向點手機都能換下一位。
- 視覺質感要像一個獨立的高品質桌遊工具。

## 最重要互動原則

多人桌遊模式不是「多人分割畫面，各按各的」。

多人桌遊模式必須是：

- 整個主畫面都是大型觸控區。
- 點任意主畫面 = 換下一位。
- 不要求玩家精準點自己的區域。
- 不使用四邊分割作為主要操作方式。
- 主視覺集中在目前玩家、倒數時間、下一位玩家、玩家順序。

二人下棋可以使用棋鐘式上下分割，但三人以上請使用桌中央任意點擊邏輯。

## 優先順序

1. 美觀度與桌上實際使用體驗
2. 互動直覺與可靠性
3. 功能完整
4. 舊版相容性最低，可以放棄

## 必要功能

### 遊戲模式

- 二人棋鐘模式。
- 多人桌遊輪流模式。
- 自由輪流模式，可只記錄輪到誰與時間。

### 玩家

- 預設玩家 1 / 玩家 2 / 玩家 3 / 玩家 4。
- 支援 2 到 6 人。
- 每位玩家可改名。
- 有常用玩家名單。
- 可快速把本局玩家替換成常用玩家。
- 可調整玩家順序。
- 可儲存常用組合更佳。

### 時間

- 可設定每回合時間，例如 60 秒。
- 可設定倒數提醒秒數。
- 可設定超時後自動換下一位或手動換下一位。
- 可暫停、繼續、重開。

### 倒數提醒

- 預設剩 10 秒開始明顯提醒。
- 剩 5 秒每秒加強提醒。
- 可包含視覺、音效、震動。
- 超時狀態必須明確。

## 美術要求

美觀度是最高優先。

視覺方向：

- 高級桌面遊戲工具感。
- 大數字、大名字、大觸控區。
- 玩家色彩鮮明但有質感。
- 適合放在桌上遠看。
- 目前玩家必須一眼可見。
- 可以重新生成美術素材、背景、光效、圖示。

避免：

- 不要像臨時工具頁。
- 不要把主要操作藏在小按鈕。
- 不要廉價閃爍。
- 不要讓多人模式變成四人各按角落。

## 動畫要求

- 玩家切換時有流暢轉場。
- 目前玩家有呼吸光暈。
- 倒數環隨時間縮短。
- 最後 10 秒色彩逐漸緊張。
- 最後 5 秒有節奏提醒。
- 暫停時有霧面或降噪效果。
- 超時時有高級、明確、但不刺眼的警示動畫。
- 點擊換人要有明顯回饋。

## 畫面建議

### 入口卡

- 顯示「桌遊計時器」定位。
- 顯示目前模式、玩家數、時間設定摘要。
- 明確引導進入全螢幕桌面模式。
- 縮小狀態只做摘要與引導，不承擔完整遊戲操作。

### 多人桌遊全螢幕

- 中央最大：目前玩家名稱 + 巨大倒數。
- 次要資訊：下一位玩家、玩家順序。
- 整個主畫面可點擊換下一位。
- 玩家順序可用環形、隊列、接力棒、座位指示呈現。
- 不要把四個角落設計成主要按鈕。

### 二人棋鐘全螢幕

- 可以上下分割。
- 要像高品質棋鐘。
- 雙方時間遠看清楚。
- 當前玩家狀態明確。
