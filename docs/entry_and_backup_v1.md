# 入口、原版前導與帳號備份整合

2026-09-11，獨立 `codex/experience-redesign`，App ID `com.yayoi991331.habitapp.redesign`。

## 本輪行為

啟動資料準備完成後會停在新的家門入口。首次使用可從「走進這個家」選 Apple／Google，
或先以訪客進入；訪客紀錄留在裝置，之後在「設定 → 帳號與備份」綁定。
已完成前導者點「回到兔咪身邊」直接接續日常，不重播前導、不重設紀錄。
資料準備失敗留在可重試畫面，不用無限等待代替錯誤。

前導參考最原本的滿版 `onboarding_bg_v3.png` 暖天空，取消寢室照片與文章的上下分割。
六幕已確認故事、可選命名、略過與衣櫃回憶均保留。兔咪在打招呼到取名保持位置與比例；
鍵盤升起只收起角色與已讀敘述，輸入和繼續仍可操作，背景不隨鍵盤縮放。

入口／前導／衣櫃重播固定播原版 `bgm_onboarding.m4a`（cotton bear）；
進日常才播衣櫃目前所選曲（預設 `bgm_main.m4a` / Sleeping star）。
離開前導重播恢復原曲，前導播完不推進主頁清單；靜音與降低動態偏好保留。
`EntryAudio` 持有路由所有權，避免晚到的啟動初始化和被關閉頁面搶歌。
BGM 初始化及 AudioSession 配置各合併同時進行的請求，失敗可重試；啟動的延遲暖機只保留音效。
這避免慢速初始化在新音樂已升起後又把音量歸零，原本 AOT 播放救援與淡入保持不變。

## 帳號與雲端的真實狀態

Firebase Auth Apple／Google 真實 adapter、同 UID 連結另一登入方式、登出、帳號刪除底層、
Firestore 分片備份、校驗、衝突檢查已提供。尚未設定 Firebase 專案、OAuth client、
Apple entitlement 與 provider，沒有部署規則或做實際 OAuth／跨裝置雲端測試。
缺配置時 Apple／Google 按鈕停用並說明原因，訪客與備份檔功能保持可用。
這不等於真實登入與雲端服務已啟用。設定步驟及未部署規則見 [後台設定](account_setup.md)。

本版雲端備份採使用者主動按「立即備份」。沒有背景 timer、pause observer 或自動上傳。
自動審核拒絕了未確認 Firebase 目的地及資料範圍的定期上傳接入；待使用者確定專案與範圍後再接。
既有雲端紀錄與本機紀錄不同時要明確選擇接續雲端或用本機更新，不能登入就覆蓋。
成功時間只根據伺服器成功回覆顯示。未連線不假裝成功；沒有家庭多人同步功能。
未發布分塊的等待有上限，晚到分塊不會自行變成新存檔；提交結果不明時顯示「備份結果仍在確認中」，
使用者可返回日常或匯出本機存檔。原生提交尚未結束時拒絕另一筆雲端操作，稍後重新讀伺服器確認。
停止等待不等於取消上傳；清理舊快照也不延遲已確認成功的結果。

## 可攜備份

「自己保留一份」可匯出 JSON，透過系統分享選單存到檔案／iCloud Drive；
不把分享選單關閉當成已保存成功。還原從系統檔案挑選器讀入，先驗證格式、型別、
版本、大小、內容結構及 SHA-256，再顯示時間與取代確認。
SHA-256 是損壞偵測，不是加密；檔案包含個人與家庭紀錄，介面提醒妥善保存。

備份涵蓋個人偏好、習慣／歷史、喝水、體重、計時設定與統計、家庭紀錄、金幣、
衣櫃／音樂選擇、兔咪故事及回憶。排除 OAuth 憑證、家長 PIN、開發者預覽、裝置通知及音訊快取。
實際白名單與型別以 `BackupArchive` 為準，新 key 不會默默納入上傳。

設定內還原會先回入口，結束功能頁再選存檔。確認後先寫 journal；整棵 App 重啟時，
在換日、資料頁和任何 migration 前恢復。每筆寫入核對、完整持久化確認後才清 journal。
中斷或失敗可重試；啟動先重新讀取磁碟再檢查 journal，不能信任失敗後的 optimistic cache。
未完成時繼續還原，已持久完成時重複執行無作用；有 pending journal 時禁止匯出半份紀錄。
還原家庭紀錄且本機沒有家長 PIN 時，入口要求先設密碼再進日常；確認 PIN 已持久化才解除入口保護。

匯出透過 `StorageSnapshotGate` 等待完整操作結束，再阻擋新寫入至快照完成。
確認對話不持有這把鎖；保護購買扣款與衣櫃、積分與帳目、票券、三個回憶鍵等相依狀態。
此協調不等於多 key 寫入失敗時的交易回滾；失敗恢復仍由既有 store 負責。
