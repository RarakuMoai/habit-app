# iPhone 14 Pro Max：本輪實機回饋

使用者以 iPhone 14 Pro Max 日常執行為主要驗收，通常不使用模擬器。
AI 先做程式與素材檢查，模擬器只補充版面資訊；音訊、觸覺、流暢度與外觀由本人最後確認。
本清單適用於包含 `839bed5` 的版本；睡衣目前仍為選款樣稿，尚未放進衣櫃。

## 先花約五分鐘看這四件事

| 操作 | 預期／回報重點 |
| --- | --- |
| 首頁點聊天，等字幕結束後按住選項，再移開取消；另試一次放開選取 | 按住有輕微回饋，取消不換句，成功選取只前進一句；回報太弱、太彈、太慢或不好點的位置 |
| 走「先陪你坐一下」分支，然後「稍後再聊」；再次進出對話 | 主選單正常消失／恢復，原習慣列表及進度不變；沒有突兀閃白、水平接縫、裁切或難以返回 |
| 字幕出現時切到背景，再回來；分別試開聲與靜音 | 同句 MI 不重播或重疊；字幕可看懂、不因靜音卡住；回報聲音晚到、突然大聲、音樂中斷等實際現象 |
| 開啟系統「減少動態效果」，再試同段對話；若平常用大字級也照日常設定測 | 選項仍有可辨識回饋與完整文字，無按壓縮放；長字可以捲動，不擠掉退出操作 |

回覆格式：`App 版本／iOS 版本；哪個操作；實際看到或聽到什麼；每次或偶發`。
外觀／銜接問題附短螢幕錄影最有效；觸覺強弱用文字即可。
不用為這輪重設資料、改系統日期或逐一測所有功能。

## 睡衣選定且整套接入後才驗

- 衣櫃穿上 → 回首頁 → 重新啟動仍穿同一套；換回原造型正常。
- 待機與眨眼、摸頭、邀請、睡眠／醒來、完成習慣：不中途脫衣、不跳回原圖、不閃缺圖。
- 在房間中的真實顯示尺寸看領口、袖口、耳朵遮擋、腳底位置與淡入淡出；褲襠不鼓包、不呈現下墜裝重物的感覺。
- 只回報仍看得見的異常與個人偏好；AI 先提供整套表情對照、接縫放大與素材檢查結果。

在同一實機、相同 App profile／release 版本與場景比較；記錄低耗電模式、是否充電與測試時間。
